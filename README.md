# ☕ MyProjects_JAVA - Curso em Vídeo

Repositório criado para armazenar **atividades, exercícios e projetos** desenvolvidos ao longo do **Curso de Java do [Curso em Vídeo](https://www.cursoemvideo.com/)**, ministrado pelo professor **Gustavo Guanabara**.  
O objetivo é registrar o progresso de aprendizado e reunir todo o conteúdo prático em um único local.

---

## 📘 Sobre o curso

O curso aborda desde os **conceitos básicos da linguagem Java** até tópicos mais avançados, proporcionando uma base sólida em **programação orientada a objetos** e **boas práticas de desenvolvimento**.

### 🧩 Principais temas estudados
- Introdução ao Java e instalação do ambiente  
- Tipos de dados, variáveis e operadores  
- Estruturas condicionais e de repetição  
- Métodos e funções  
- Programação Orientada a Objetos (POO)  
- Criação de classes, objetos e construtores  
- Encapsulamento, herança e polimorfismo
